# Vinheria Agnello

## Nome do projeto

Vinheria Agnello

## Descrição

Página simples inspirada em uma vinheria online, com layout em Flexbox e efeitos visuais com pseudo-classes e transformações CSS.

## Recursos usados

- Flexbox
- Pseudo-classes (:hover e :focus)
- Transformações CSS
- CSS separado em arquivo próprio
